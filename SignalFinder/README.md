# كاشف الإشارات (SignalFinder) 📡

تطبيق iPhone بيلقط أجهزة **البلوتوث (BLE)** القريبة منك وبيطلّع **طنين** متل عدّاد غايغر:
كل ما تقرّب على الجهاز، الطنين بيصير **أسرع** والصوت **أعلى**.

## شو بيعمل

- بيفحص كل أجهزة Bluetooth Low Energy حواليك وبيعرض بس اللي ضمن المدى اللي بتختاره (افتراضياً **10 م**).
- **وضع المسح:** بيطنّ حسب أقوى جهاز ضمن المدى.
- **وضع التتبع:** اضغط على جهاز، وبيصير الطنين يتبع هالجهاز لحاله، مع نسبة قوة الإشارة، مسافة تقريبية، ومؤشر «عم تقرّب / عم تبعد».
- بيتعرّف على بعض المتتبعات (AirTag / Find My، Tile، Samsung SmartTag) وبيعلّمها بالأحمر.
- صوت + اهتزاز (بيشتغل حتى لو الموبايل على الصامت).
- فيك تسحب على جهاز لتتجاهله (مثلاً سماعاتك أو ساعتك).

## حدود لازم تعرفها ⚠️

| | |
|---|---|
| ✅ بيلقط | أجهزة Bluetooth LE: سماعات، ساعات، متتبعات، موبايلات، أجهزة ذكية… |
| ❌ ما بيلقط | **Wi-Fi**: Apple ما بتسمح لأي تطبيق يفحص شبكات Wi-Fi |
| ❌ ما بيلقط | Bluetooth الكلاسيكي، إشارات الموبايل (GSM/LTE)، 433 MHz، أجهزة تنصّت أنالوج |
| ⚠️ المسافة | تقديرية، لأن الجدران والأجسام بتأثر على الإشارة. اعتمد على **الاتجاه** (أقرب/أبعد) أكتر من الرقم |
| ⚠️ الخلفية | iOS بيوقف الفحص إذا سكّرت التطبيق، لهيك الشاشة بتضل شغالة وقت الفحص |

لكشف **كل** أنواع الإشارات بتحتاج جهاز مخصص (RF detector) أو SDR، والموبايل لحاله ما بيقدر.

## التثبيت على الآيفون

### الطريقة 1: عندك Mac
1. افتح `SignalFinder.xcodeproj` بـ Xcode.
2. من **Signing & Capabilities** اختار الـ Team تبعك (Apple ID العادي بيكفي).
3. وصّل الآيفون واضغط ▶️ Run.

### الطريقة 2: ما عندك Mac (Windows)
1. كل push بيبني التطبيق تلقائياً بـ GitHub Actions (workflow اسمه **SignalFinder iOS build**).
2. نزّل `SignalFinder-unsigned-ipa` من صفحة الـ run تحت **Artifacts**.
3. ثبّت الملف بـ [Sideloadly](https://sideloadly.io) أو AltStore/SideStore باستخدام Apple ID تبعك.
4. على الآيفون: **الإعدادات ← الخصوصية والأمان ← وضع المطوّر** شغّله، وبعدها **الإعدادات ← عام ← VPN وإدارة الجهاز** وثق بالشهادة.

> مع Apple ID مجاني، التطبيق بيشتغل **7 أيام** وبعدها لازم تعيد تثبيته (Sideloadly/AltStore بيعملوا هالشي بسهولة).

## الاستخدام
1. افتح التطبيق واسمح باستخدام البلوتوث.
2. حدد المدى بالـ slider.
3. لتلاقي جهاز معيّن: اضغط عليه، وامشِ ببطء ولفّ حوالين حالك. كل ما صار الطنين أسرع، يعني قرّبت.

## التقنيات
Swift · SwiftUI · CoreBluetooth · AVAudioEngine. بيشتغل على iOS 16 وأحدث.
المسافة محسوبة بنموذج log-distance path loss، والـ RSSI منعّم بـ exponential smoothing حسب الزمن.
